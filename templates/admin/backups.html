Restore procedure

Automated restore is not enabled. The deployed app uses Supabase PostgreSQL and Render has no persistent disk configured; application-local files are not a durable production backup store. Restore through the Supabase managed recovery workflow or an authorized PostgreSQL operator during a maintenance window. Validate a backup against a staging project first, preserve a fresh pre-restore snapshot, and never replace production using ordinary application SQL.
