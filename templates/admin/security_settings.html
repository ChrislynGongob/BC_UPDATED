Password policy

Passwords must be {{ min_password_length }}–{{ max_password_length }} characters and include at least one letter and one number. Common passwords are blocked. Password values are stored as secure one-way hashes.

Administrator multi-factor authentication

Every administrator, including the Founding Admin, verifies sign-in with a single-use code sent to the registered email address. Codes expire after {{ otp_ttl }} minutes, allow {{ otp_attempts }} attempts, and can be sent {{ otp_sends }} times per hour with a {{ otp_resend_seconds }} second resend delay. Delivery credentials are configured on the server and are never shown here.

Login protection and sessions

Each account locks for {{ lockout_minutes }} minutes after {{ max_failed_logins }} consecutive failed password attempts. An IP address is temporarily rate limited after {{ login_rate_limit }} failed sign-ins in {{ login_rate_window }} minutes. Administrator sessions expire after {{ session_idle_minutes }} minutes of inactivity. Session cookies use HttpOnly and SameSite=Lax; Secure is enabled in production.
